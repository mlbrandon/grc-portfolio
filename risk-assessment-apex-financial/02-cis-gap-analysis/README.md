# CIS Controls IG1 Gap Analysis: Apex Financial Partners (Fictional Firm)

Gap analysis of Apex Financial Partners, a fictional 30-person financial advisory firm, against all 56 CIS Controls v8.1 Implementation Group 1 (IG1) safeguards. Builds on the Apex risk register (Project 1).

## Results
- Overall IG1 coverage: about 13% (2 Implemented, 11 Partial, 43 Not Implemented)
- 27 high-priority gaps, each linked to a risk in the Apex risk register
- 90-day remediation roadmap in three phases (0–30, 31–60, 61–90 days)

## Files
- [Gap Analysis Workbook](Apex-CIS-IG1-Gap-Analysis.xlsx): safeguard scoring, control summary, and roadmap
- [Executive Summary](Apex-CIS-Gap-Analysis-Executive-Summary.pdf): one-page overview for leadership

## Notes
- This project uses CIS Controls v8.1. The Project 1 risk register cites v8; safeguard references are consistent across both.
- Fictional firm. All current states and scores are my own judgments for a hypothetical organization. No systems were tested or scanned.
- Safeguard IDs and titles: CIS Critical Security Controls v8.1, Center for Internet Security, licensed CC BY-NC-ND 4.0.
